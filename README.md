# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي بأسلوب العرض التقديمي (Presentation) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون اعتماديات أو خطوات بناء، بالعربية افتراضياً مع نسخة إنجليزية.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الشرائح
1. **الواجهة:** مقدمة متحركة (الشعار يطفو ثم يلتف ويستقر في الشريط العلوي)، ثم صورة تبدأ قريبة وتبتعد تدريجياً.
2. **من نحن:** خبرة ميدانية منذ 2007 — تصميم · تنفيذ · إشراف.
3. **مواقع مختارة:** معرض صور متحرك، ويفتح كل صورة بالحجم الكامل عند الضغط عليها.
4. **خدماتنا:** قائمة الخدمات السبع.
5. **تواصل معنا:** الهاتف، واتساب، البريد الإلكتروني، والموقع على خرائط Google.

## إعدادات يجب إكمالها
في أعلى الملف `assets/js/main.js`:
```js
var CONFIG = {
  EMAIL: "",      // البريد الإلكتروني للشركة — بطاقة البريد تبقى مخفية حتى يُملأ
  MAPS: "...",    // رابط موقع الشركة على خرائط Google (الدبوس ← مشاركة ← نسخ الرابط)
  WHATSAPP: "9647718000711"
};
```

## هيكل الملفات
```
index.html                 الصفحة (النص العربي)
assets/css/style.css       التصميم والحركات والتجاوب
assets/js/main.js          المقدمة المتحركة، الشرائح، معرض الصور، الترجمة الإنجليزية
assets/img/logo-mark.svg   رمز الشعار (نسخة بيضاء: logo-mark-white.svg)
assets/img/site/           صور المواقع الثلاث (JPG + WebP بحجمين)
```

## تعديل المحتوى
- **النص العربي** داخل `index.html`، و**النص الإنجليزي** في كائن `EN` داخل `main.js` بنفس مفاتيح `data-i18n`.
- **استبدال صورة:** ضع الصورة الجديدة في `assets/img/site/` بنفس الاسم، أو غيّر المسارات في عنصر `<picture>`.
- الحركات تتوقف تلقائياً عند من فعّل خيار «تقليل الحركة» في جهازه، ويمكن تخطي المقدمة بالضغط على الشاشة.
