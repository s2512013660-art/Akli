# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي بأسلوب العرض التقديمي (Presentation) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون اعتماديات أو خطوات بناء، بالعربية افتراضياً مع نسخة إنجليزية.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التصميم
- **مصمم للجوال:** تصميم واحد بمقاسات الجوال، وكل الأحجام تتناسب مع عرض الشاشة فيبدو بنفس الشكل على كل الهواتف.
  على الآيباد والكمبيوتر يظهر كعمود بشكل شاشة الجوال في وسط الصفحة.
- **خفيف:** الشاشة الأولى تحتاج صورة واحدة (حوالي 35–70 كيلوبايت بصيغة AVIF) والخط، والباقي يُحمَّل لاحقاً.
  على شبكة 3G تجهز صورة الواجهة خلال حوالي ثانيتين، قبل انتهاء حركة الشعار.

## الشرائح
كل شريحة فيها الصورة **كاملة بعرض الشاشة** والكتابة في مساحة مستقلة فوقها أو تحتها، وخلفها نسخة ضبابية معتمة من نفس الصورة.
1. **الواجهة:** مقدمة متحركة (الشعار يطفو ثم يلتف ويستقر في الشريط العلوي)، ثم تظهر الصورة مقرّبة على المبنى وترجع لوضعها الكامل، وتحتها الكتابة.
2. **من نحن:** «خبرة ميدانية منذ 2007» فوق صورة الصب الليلي، و«تصميم · تنفيذ · إشراف» تحتها.
3. **مواقع مختارة:** مربعات المشاريع وتحت كل مربع اسم المشروع، وتُمرَّر بالعرض.
4. **خدماتنا:** صورة الهيكل ثم صورة السقف من الأعلى تتبادلان (كلتاهما كاملة)، وتحتهما قائمة الخدمات السبع.
5. **تواصل معنا:** الهاتف، واتساب، البريد الإلكتروني، والموقع على خرائط Google.

## إضافة صورة لمشروع أو مشروع جديد
- **صورة لمشروع موجود:** ضع الصورة في مجلد `assets/img/projects/` (يفضّل مربعة أو قريبة من المربع، بعرض 800–1200 بكسل)،
  ثم أضفها داخل مربع المشروع في `index.html`:
  ```html
  <div class="project-media"><img src="assets/img/projects/kamaliyat-bridge.jpg" alt="جسر الكماليات" loading="lazy"></div>
  ```
  الصورة تملأ المربع تلقائياً، وتفتح بالحجم الكامل عند الضغط عليها.
- **مشروع جديد:** انسخ عنصر `<li class="project anim">…</li>` داخل `<ul class="rail">` وغيّر الاسم،
  واجعل له مفتاحاً جديداً (مثل `data-i18n="p11"`) وأضف اسمه الإنجليزي في كائن `EN` داخل `main.js`.

## هيكل الملفات
```
index.html                 الصفحة (النص العربي)
assets/css/style.css       التصميم والحركات والتجاوب
assets/js/main.js          المقدمة المتحركة، الشرائح، شريط المشاريع، تبديل صور الخدمات، الترجمة الإنجليزية
assets/fonts/              خط Alexandria (مضمّن في الموقع ومخفّف للعربية واللاتينية، رخصة OFL)
assets/img/logo-mark.svg   رمز الشعار (نسخة بيضاء: logo-mark-white.svg)
assets/img/site/           صور الموقع الأربع كاملة (AVIF + WebP + JPG)
tools/build-images.py      أداة تُنشئ أحجام الصور من الصور الأصلية
```

## تعديل المحتوى
- **النص العربي** داخل `index.html`، و**النص الإنجليزي** في كائن `EN` داخل `main.js` بنفس مفاتيح `data-i18n`.
- الحركات تتوقف تلقائياً عند من فعّل خيار «تقليل الحركة» في جهازه، ويمكن تخطي المقدمة بالضغط على الشاشة.

## الصور
- كل صورة تُعرض كاملة دون قص، محفوظة بعرضين (800 و1200 بكسل) بصيغة AVIF وWebP، والمتصفح يختار الأنسب لشاشته.
- الصور الحالية رُفعت دقتها بتقنية Real-ESRGAN لأن النسخ المتوفرة كانت منخفضة الدقة.
- **لاستبدالها بصور أصلية من الكاميرا أو الدرون:**
  ```bash
  python3 tools/build-images.py الواجهة.jpg الصب-الليلي.jpg الهيكل.jpg السقف.jpg
  ```
