# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي ثنائي اللغة (عربي/إنجليزي) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون أي اعتماديات أو خطوات بناء.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
يمكن نشره مباشرة على GitHub Pages أو Netlify أو أي استضافة ثابتة.

## هيكل الملفات
```
index.html               الصفحة الرئيسية (المحتوى العربي الافتراضي)
assets/css/style.css     الهوية البصرية والتجاوب والحركات
assets/js/main.js        اللغة، المشاريع، النوافذ، العدادات، Scroll Reveal
assets/img/              الشعار والأيقونة ورسومات المشاريع
```

## إضافة مشروع أو استبدال الصور
1. ضع صورة المشروع الحقيقية في `assets/img/projects/` (يفضل JPG/WebP بعرض ~1600px).
2. في `assets/js/main.js` عدّل مصفوفة `PROJECTS`: أضف عنصراً جديداً أو غيّر قيمة `image`.
   كل مشروع يحتوي نصاً عربياً (`ar`) وإنجليزياً (`en`) وتصنيفاً `category`:
   `water` | `bridges` | `buildings`. اجعل `featured: true` لعرض المشروع ببطاقة عريضة.
3. يمكن إضافة `location` داخل `ar`/`en` لإظهار الموقع على البطاقة.

> الصور الحالية رسومات توضيحية مؤقتة، ونطاق الأعمال المكتوب لكل مشروع وصف عام — يرجى مراجعته وتحديثه بالتفاصيل الفعلية.

## الترجمة
النص العربي يُقرأ مباشرة من `index.html`، والنص الإنجليزي في كائن `EN` داخل `main.js`
(بنفس مفاتيح `data-i18n`). يُحفظ اختيار اللغة في المتصفح.
