# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي ثنائي اللغة (عربي/إنجليزي) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون أي اعتماديات أو خطوات بناء.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
يمكن نشره مباشرة على GitHub Pages أو Netlify أو أي استضافة ثابتة.

## هيكل الملفات
```
index.html                 الصفحة (النص العربي الافتراضي)
assets/css/style.css       التصميم والتجاوب
assets/js/main.js          الترجمة الإنجليزية، القائمة، الحركات
assets/img/logo-mark.svg   رمز الشعار (نسخة بيضاء: logo-mark-white.svg)
assets/img/site/           صور مواقع العمل (JPG + WebP بحجمين)
```

## تعديل المحتوى
- **النص العربي** داخل `index.html` مباشرة، و**النص الإنجليزي** في كائن `EN` داخل `main.js` بنفس مفاتيح `data-i18n`.
- **إضافة مشروع:** انسخ عنصر `<li>` داخل `.project-list` وغيّر الاسم والمجال، وأضف الترجمة في `EN`.
- **استبدال صورة:** ضع الصورة في `assets/img/site/` بنفس الاسم، أو غيّر المسارات في عنصر `<picture>`.
