# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي ثنائي اللغة (عربي/إنجليزي) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون أي اعتماديات أو خطوات بناء.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
يمكن نشره مباشرة على GitHub Pages أو Netlify أو أي استضافة ثابتة.

## هيكل الملفات
```
index.html               الصفحة (المحتوى العربي الافتراضي)
assets/css/style.css     الألوان والتصميم والتجاوب
assets/js/main.js        الترجمة، القائمة، شريط المشاريع، الحركات
assets/img/logo-mark.svg الشعار (نسخة فاتحة: logo-mark-light.svg)
assets/img/site/         صور مواقع العمل (JPG + WebP بحجمين)
```

## تعديل المحتوى
- **النصوص العربية** داخل `index.html` مباشرة، و**الإنجليزية** في كائن `EN` داخل `main.js` بنفس مفاتيح `data-i18n`.
- **إضافة مشروع:** انسخ عنصر `<article class="slide">` داخل `#slider` في `index.html`، وغيّر الرقم والعنوان.
  لإضافة صورة للمشروع أضف الصنف `has-photo` وعنصر `<picture>` كما في المشروع 03، وضع الصورة في `assets/img/site/`.
- عند إضافة نص جديد بالعربية أضف له مفتاح `data-i18n` وترجمته في `EN`.

> الصور بالأبيض والأسود افتراضياً وتظهر ملونة عند تمرير المؤشر عليها.
