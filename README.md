# بوابة الإعمار للمقاولات العامة — BAWABAT AL-EMAR

موقع تعريفي بأسلوب العرض التقديمي (Presentation) لشركة بوابة الإعمار للمقاولات العامة — كربلاء، العراق.
موقع ثابت (HTML / CSS / JavaScript) بدون اعتماديات أو خطوات بناء، بالعربية افتراضياً مع نسخة إنجليزية.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الشرائح
1. **الواجهة:** مقدمة متحركة (الشعار يطفو ثم يلتف ويستقر في الشريط العلوي)، ثم تظهر الصورة مقرّبة على المبنى وترجع لوضعها الطبيعي، وبعدها الكتابة.
2. **من نحن:** خبرة ميدانية منذ 2007 — تصميم · تنفيذ · إشراف، فوق صورة الصب الليلي بالمضخات.
3. **صورة من الموقع:** صورة السقف من الأعلى معروضة كاملة دون قص أو تعتيم.
4. **مواقع مختارة:** مربعات المشاريع وتحت كل مربع اسم المشروع، وتُمرَّر بالعرض (سحب، أسهم، أو لوحة اللمس).
5. **خدماتنا:** قائمة الخدمات السبع فوق صورة خلفية.
6. **تواصل معنا:** الهاتف، واتساب، البريد الإلكتروني، والموقع على خرائط Google.

## إضافة صورة لمشروع أو مشروع جديد
- **صورة لمشروع موجود:** ضع الصورة في مجلد `assets/img/projects/` (يفضّل مربعة أو قريبة من المربع، بعرض 800–1200 بكسل)،
  ثم أضفها داخل مربع المشروع في `index.html`:
  ```html
  <div class="project-media"><img src="assets/img/projects/kamaliyat-bridge.jpg" alt="جسر الكماليات" loading="lazy"></div>
  ```
  الصورة تملأ المربع تلقائياً، وتفتح بالحجم الكامل عند الضغط عليها.
- **مشروع جديد:** انسخ عنصر `<li class="project anim">…</li>` داخل `<ul class="rail">` وغيّر الاسم،
  واجعل له مفتاحاً جديداً (مثل `data-i18n="p11"`) وأضف اسمه الإنجليزي في كائن `EN` داخل `main.js`.

## هيكل الملفات
```
index.html                 الصفحة (النص العربي)
assets/css/style.css       التصميم والحركات والتجاوب
assets/js/main.js          المقدمة المتحركة، الشرائح، شريط المشاريع، الترجمة الإنجليزية
assets/fonts/              خط Alexandria (مضمّن في الموقع، رخصة OFL)
assets/img/logo-mark.svg   رمز الشعار (نسخة بيضاء: logo-mark-white.svg)
assets/img/site/           صور الموقع الأربع (WebP بعدة أحجام + نسخة طولية للجوال + JPG)
tools/build-images.py      أداة تُنشئ أحجام الصور من الصور الأصلية
```

## تعديل المحتوى
- **النص العربي** داخل `index.html`، و**النص الإنجليزي** في كائن `EN` داخل `main.js` بنفس مفاتيح `data-i18n`.
- الحركات تتوقف تلقائياً عند من فعّل خيار «تقليل الحركة» في جهازه، ويمكن تخطي المقدمة بالضغط على الشاشة.

## صور الخلفيات ودقتها
- الصور الحالية رُفعت دقتها بتقنية Real-ESRGAN لأن النسخ المتوفرة كانت منخفضة الدقة (مضغوطة من تطبيقات المراسلة).
- لكل صورة نسخ عرضية بعدة أحجام للشاشات العريضة، ونسخة طولية مقصوصة (3:4) للجوالات، والمتصفح يختار الحجم المناسب لدقة الشاشة.
- **لأفضل وضوح:** استبدلها بالصور الأصلية من الكاميرا أو الدرون، ثم شغّل:
  ```bash
  python3 tools/build-images.py الواجهة.jpg الصب-الليلي.jpg السقف-من-الأعلى.jpg الخدمات.jpg
  ```
  فيُنشئ كل الأحجام المطلوبة في `assets/img/site/` بنفس الأسماء.
